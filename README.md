# Gataria Store — Sprint Produtos v1.1

## Rodar no Windows

```powershell
npm install
npm run dev
```

Abra `http://localhost:3000` e o painel em `http://localhost:3000/admin`.

## Melhorias desta versão

- Galeria com até 10 imagens por produto
- Categoria em lista
- Marca e peso para frete
- Preço promocional
- Seletores visuais de cores, tamanhos e modelos
- Descrição comercial e história da arte
- Etiquetas do produto
- Campos básicos de SEO
- Salvar como rascunho ou publicar
- Exibição de promoção, etiquetas e história na página do produto

Os dados continuam salvos no navegador por `localStorage`. Depois de editar, clique em **Publicar alterações** no topo do painel.
