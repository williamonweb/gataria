# Gataria Store

Primeiro protótipo navegável da home da Gataria, baseado no layout aprovado.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Escopo desta entrega

- Home responsiva fiel ao conceito aprovado
- Header, hero, categorias, produtos, coleções, produto da semana, avaliações, Instagram e rodapé
- Interações básicas de carrinho, tamanho e menu mobile
- Estrutura Next.js 14 pronta para evolução

## Próximas integrações

Banco de dados, painel administrativo, login, carrinho persistente, checkout, PIX/cartão, frete por CEP e gestão de pedidos.
